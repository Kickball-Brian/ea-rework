EMAIL AGENCY — WORDPRESS TO REACT MIGRATION NOTES
===================================================
Old site:  emailagency.com (WordPress, Avada/Fusion Builder theme, Yoast SEO)
New site:  emailagency.com (React 19 SPA — Vite, React Router, hosted on Netlify)
Notes as of: 2026-09-17

A WordPress export/backup of the old site will be uploaded separately alongside
this folder for anyone who needs to reference the original content, media, or
plugin configuration directly.


1. PLATFORM CHANGE
-------------------
Old:  WordPress + Avada theme + Fusion Builder page builder. Plugins included
      Yoast SEO, Contact Form 7, RevSlider, WP Carousel, a popup-message
      plugin, a date/time picker, and others typical of an Avada build.
New:  React 19 single-page app built with Vite, routed client-side with
      React Router, animated with GSAP/ScrollTrigger + Framer Motion, smooth
      scroll via Lenis. Deployed to Netlify (static build + serverless
      redirects, see netlify.toml).

Practical effect: there is no WordPress admin anymore. Content that used to
be editable by a non-technical person in wp-admin is now hardcoded in the
React source (mainly src/pages/*.jsx and src/data/solutions.js) and requires
a code change + deploy to update.

3. CONTENT CHANGES
-------------------
- Homepage: completely redesigned. The old Avada/RevSlider homepage is
  replaced by a custom scroll-driven experience (pinned hero, scroll-scrubbed
  video, pinned horizontal solutions carousel, animated team marquee).
- Team section: rebuilt as an infinite-scrolling headshot marquee. Every
  team member listed on the old About page is carried over; Mark Muzzini's
  headshot was added during this migration (he previously showed as an
  initials placeholder pending a photo).
- Solutions: the old site effectively had two solution-adjacent pages
  (lead-generation and data-lists). The new site has six dedicated solution

  It was never wired up with real content and was fully removed rather than

4. SEO / TECHNICAL CHANGES
----------------------------
- Structured data: the old site's Yoast-generated schema (Organization,
  WebSite, BreadcrumbList, WebPage) is replaced with hand-written JSON-LD —
  an Organization + WebSite block sitewide (index.html) plus a BreadcrumbList
  injected per page (src/hooks/usePageMeta.js).
- Google Tag Manager: container GTM-NBV9D6KW is installed (index.html). Since
  this is a client-side-routed SPA and the document never reloads between
  pages, a custom "virtualPageview" event is pushed to dataLayer on every
  route change (GTM's own page-load trigger would otherwise only ever see
  the first URL a visitor lands on).
- robots.txt and sitemap.xml were rebuilt from scratch to match the new
  route list in section 2, rather than carried over from Yoast's output.
- 301 redirects: every legacy WordPress URL that had real content, a real
  external link, or meaningful crawl history was identified via a full
  crawl of the old site's Yoast XML sitemaps and mapped to a redirect (see
  netlify.toml and section 2 above).
- Accessibility: a skip-to-content link was added (first focusable element
  on every page).
- Performance: every route now lazy-loads its own JS chunk instead of one
  shared bundle, so a visitor only downloads the code for the page they're
  actually viewing.
